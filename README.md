# Fathom

Fathom is a bioluminescent deep-sea maze chase for the browser. Guide a tiny forager through a lightless trench, graze glowing plankton, reveal passages with sonar, and use ink to escape predators that hunt by light and sound.

## Run locally

```sh
npm ci
npm run dev
```

Open the URL Vite prints. Run `npm run build` to create the deployable static site in `dist/`.

## Controls

- Arrow keys or WASD: swim
- Space: sonar pulse / confirm
- Left or right Shift: release ink
- Escape or P: pause
- M: mute
- Enter: confirm

Touch controls appear automatically on touch devices.
